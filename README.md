# Rust Path — 12 weeks, every line by hand

## Rules
1. No AI code completion. rust-analyzer / tab completion is fine.
2. AI may *explain* errors/concepts. Never paste AI-written code. Stuck > 30 min → ask for a hint, not a solution.
3. Docs only: docs.rs, the Book, `cargo doc --open`.
4. A project is done only when `cargo clippy -- -D warnings` and `cargo test` are green, and the write-up is in `posts/`.

## Weekly rhythm (~10 hrs)
- Mon–Fri, 30 min: one Exercism Rust exercise or Rustlings section, from memory.
- Weekend, ~7 hrs: project work.
- Sunday, 20 min: post in `posts/` — what I learned / hardest bug.

## Checkpoint (end of every phase)
Delete one function you wrote, rewrite it from memory in 15 min. Fail → redo that part before moving on.
